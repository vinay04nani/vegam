Long memory

It writes a note after every call.And reads it before the next.

Vegham does not keep a pile of recordings to search later. It keeps the few things that matter about each person, and you can see and change every one of them.

1It listensThe whole call or chat, in whatever language it happens.
2It writes down what mattersNames, preferences, plans and anything left unfinished.
3It uses it next timeOn any channel, so nobody has to repeat themselves.
