# Contributing to Vegam

Vegam is proprietary software owned by **Vinay Kumar**. It is not open source. See [LICENSE](LICENSE).

Contributions are by invitation only.

## Before you contribute

You must have **signed a Contributor IP Assignment Agreement** with the owner before you get access to this repository or submit any work. A template is in [docs/legal/contributor-ip-assignment.md](docs/legal/contributor-ip-assignment.md).

By signing it, you agree that:

- everything you create for Vegam (code, designs, documents, ideas, improvements) belongs to the owner;
- you keep the code, product plans and business information confidential; and
- you will not use any of it for another product or company.

Pull requests from anyone without a signed agreement will be closed without review.

## How to work

- Work on a feature branch; never push directly to `main`.
- Open a pull request; every change needs review and approval from a code owner (see [.github/CODEOWNERS](.github/CODEOWNERS)).
- Follow the engineering conventions in [docs/handoff.md](docs/handoff.md) once it is added.
- Never commit secrets, API keys, customer data or personal data.
- Do not add third-party code or libraries whose license conflicts with proprietary use (for example GPL or AGPL) without the owner's written approval.
